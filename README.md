# Recipe Lab

Моя коллекция домашних рецептов с ингредиентами и пошаговым приготовлением.

[Открыть сборник рецептов](https://streeet25.github.io/recipes/)

## Рецепты

- [Боул с курицей, авокадо и кукурузой](./avocado_chicken_bowl_recipe.html) — без лука, без остроты, на 2 порции.
- [Курица с картошкой на противне](./chicken_potatoes_recipe.html) — с пореем, рукколой и чесночным йогуртом. 4 порции, около 1 часа плюс маринование; есть видео.
- [Сочные котлеты со сливками и пармезаном](./juicy_chicken_cutlets_recipe.html) — куриное бедро или филе, 12–13 котлет по 125 г. Пропорции из домашней записи, отмечаемый список ингредиентов и версия для печати.
